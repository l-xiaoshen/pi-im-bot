# 插件中心：配置、获取与分发

## 管理入口

「插件中心」包含已安装、发现插件和编排；「运行环境」独立管理。实例详情提供配置、使用方法、启停、更新和删除，声明 Hook 的插件还会显示编排。

- 列表显示实例、版本、配置与依赖状态。
- 配置由包内静态 `_conf_schema.json` 生成，不为生成表单导入插件入口。
- 编排展示实际 handler、输入输出契约和可写字段；保存启停与优先级会改变调用顺序，但不能绕过依赖。
- 运行环境检查 Docker、镜像、FUSE 和文件系统工具，显示实例无法执行的具体原因。

## 获取与安装

支持以下来源：

1. 已配置的静态插件目录。
2. GitHub 仓库、分支、标签、commit、子目录、Release 页面或 ZIP。
3. 直接 HTTP(S) ZIP 地址。
4. 本机 ZIP 上传或开发目录。

GitHub 源码先固定到 commit。没有 Release 时可安装源码，但包必须包含 `plugin.json`、运行入口及其依赖；安装过程不执行入口、依赖安装或构建脚本，也不使用宿主 SSH 凭据。

下载、校验和安装作为独立管理任务运行，不占用群主对话。包内容按 SHA-256 保存为不可变快照，更新时先准备新快照，再切换实例 release；失败不会替换可用版本。

首次安装创建停用实例。更新保留设置与数据；如果更新使已启用实例的配置或依赖无效，应用会被拒绝并保留当前 release。可先停用实例，再更新并补全配置。新声明的授权不会自动授予已有实例。

卸载保留配置归档、私有数据和产物。实例仍被范围、权限规则或其他插件依赖引用时，需要先解除引用。

## 配置与继承

`_conf_schema.json` 支持嵌套对象、文本、数值、布尔、列表、字典、模板、条件显示、选项、secret 和资源选择器。服务端校验类型、数值范围、资源引用和允许的作用域。

```text
实例基础配置 → Bot 默认覆盖 → 账号 → 聊天范围 → 当前 conversation
```

对象按字段合并，数组与字典整体覆盖。恢复继承会删除本层值；空字符串、`false`、空数组和空字典仍是明确覆盖。

秘密字段只在实例层保存，读取接口仅返回是否已设置。未修改时保留，替换或清除需要显式操作；群和 conversation 覆盖不能承载秘密值。

manifest 的 `connections` 声明 MCP、具名服务或插件依赖。资源选择器生成服务引用，不代表插件因此获得任意网络或 Provider 调用能力。只有显式 `required` 的依赖阻止实例启用。

## 更新与分发

强制更新按原始来源重新获取：目录源读取当前索引，GitHub 使用原引用，开发目录重新导入。上传 ZIP 没有可自动获取的来源时，需要手动上传新包。

打包不会执行插件入口，输出不包含实例设置、密钥或数据：

```sh
bun run pack:plugin examples/plugins/echo /tmp/echo.zip
```

可运行示例：[回声指令](../../examples/plugins/echo/README.md)、[延时撤回](../../examples/plugins/recall/README.md)。作者侧包布局、索引格式和开发源见 [插件开发手册](../plugins/README.md)。

目录源刷新失败时保留缓存。相同语义版本但摘要不同的开发包也可识别为更新。安装来源和私有 URL 凭据不会出现在公开实例元数据中。
