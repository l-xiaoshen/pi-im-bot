# 聊天会话范围与触发人权限

## 三种标识

| 标识                    | 含义                             | 生命周期                       |
| ----------------------- | -------------------------------- | ------------------------------ |
| 聊天范围 / Room         | 某个群、私聊或 Mock/WebChat 窗口 | 跨消息、重连和多次任务保持稳定 |
| `currentConversationId` | 此范围当前选中的对话             | 新建或切换对话时改变           |
| 触发身份                | 本次调用的来源及其权限           | 绑定到具体任务与调用链         |

范围地址包含平台适配器、机器人账号、群/私聊类型和平台会话 ID。群员 sender ID 不进入群的范围地址，因此不会产生每成员一份 Agent 状态。

## 共享上下文，分别授权

群成员共享当前 conversation 的历史、人格、工具目录和资源选择。每次工具调用仍需同时满足：

```text
资源已启用且供当前范围选择
+ 工具已装载
+ 调用链的触发身份获准
+ 调用时的最新权限检查通过
```

权限只能来自可信平台事件、受信管理入口或已保存的任务创建者，不能来自昵称、模型参数或提示词。共享会话不意味着成员共享高权限。

## 多人合批

同一范围内的短间隔消息可合并处理，但保留各自的消息 ID、发言者、引用与顺序：

1. 普通群消息可作为背景，不因此触发工具或授予权限。
2. 自动工具权限取所有实际触发人的交集，不取并集，也不使用最后一位发言者代替整批。
3. 模型不能选择批次中的高权限成员作为调用者；来源不明确时保持拒绝。
4. 配置或权限上下文发生变化时另起批次。
5. Job 修订形成新版本，并按本次修订者的权限执行；旧版本不能交付迟到结果。

## 后台身份与取消

后台 Job、子 Agent、Cron 和观察任务保存原范围、conversation、来源消息、创建者和能力上限。嵌套调用只能继承或进一步收窄这些权限，并在实际操作时重新检查当前授权。

停止、切换对话、切换渠道目标或停用资源会取消相应待处理工作。已确认的外部回执与产物仍保留，结果未知的业务操作不会自动重做。

成员是否能查看、修订或取消某个共享任务由权限规则决定，而不是由“谁最后发言”决定。
